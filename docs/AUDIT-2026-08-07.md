# Audit — 2026-08-07

A whole-repo review of code and documentation: what is unnecessary, what is
written twice, what is dead, and where the docs have drifted from the build.
Seven independent audit lenses swept the tree; every finding was then
adversarially re-verified by a separate pass against the working copy, with the
verifier instructed to refute. 35 findings came back: 34 confirmed, 1 confirmed
with a corrected detail, 0 refuted. Every line number below was re-checked on
the audit date.

This file is a snapshot, dated. `OPEN.md` is current truth for what it covers;
items already tracked there are referenced here, not restated — except where
the `OPEN.md` entry itself has gone stale, which is a finding.

| lens | looked at | findings |
| :- | :- | :-: |
| dead code, data layer | `src/data`, exports, parameters | 4 |
| dead code, UI | screens, components, CSS, tokens | 5 |
| redundant code | duplication across modules | 7 |
| root cruft | untracked and vestigial files | 6 |
| stale docs, spec | `DESIGN.md` against the code | 4 |

## Unnecessary files

**The design-handoff directory is a frozen copy of the spec that now argues
with it.** `Three UI approaches for coaching app/` (8 files, 488K) has not
changed since the initial commit `62f7271` (2026-08-01), while the live
`docs/DESIGN.md` has taken eight commits since. Its `spec/DESIGN.md` mentions
objectives ten times — cut by ADR 0006 — and the handoff `README.md:14` says
"where the two ever disagree, `spec/` wins", which is now exactly backwards.
Nothing in the build references it except archived plan files and the
provenance comment at `src/styles/tokens.css:1`, and `tokens.css` holds its
values itself. Delete the whole directory; git history keeps it. If any of it
is kept, delete at least `design_handoff_daily/spec/`, and reword the
`tokens.css` comment so it does not point at a path that is gone. High.

**Twelve stale worktrees hold 187M that git no longer needs.**
`entry-time-edit-input-5b688f` alone is 183M — clean, and its branch merged as
`9f42489` (PR #18). `exercise-food-meals-42c8f8` and
`v1-plan-implementation-22117b` are both detached at `45839bf`, the PR #7
merge of 2026-08-05, an ancestor of master. The other nine
`complex-plan-phase-*` directories are 4.0K empty husks git does not even
register. All local-only (`.git/info/exclude:18`). `git worktree remove` the
three real ones, `git worktree prune`, delete the husks. This is also why
`vite.config.ts:43` needs its test-include guard. High.

**`docs/design-brief.txt` is a byte-identical duplicate of the handoff copy.**
12K, only commit `62f7271`, referenced only by the handoff README — which
points at the `spec/` copy, not this one. It is the delivered "TURN 4 BRIEF",
built and superseded; its lines ~106–111 order up an Objectives surface that
ADR 0006 removed. Delete it. Medium.

**The v1-recording archive is a deliberate keep, not cruft.**
`docs/plans/archive/v1-recording/` (9 files, 272K) is the retention the
closeout commit `28ed246` chose on purpose — `PLAN.md:732-734` says archive,
don't keep — and both `CLAUDE.md` and `OPEN.md:5-7` point into it. No action.
If it is ever deleted, edit both references in the same commit.

## Dead code

**`weekBounds` is exported for no caller but the test.** `src/data/entry.ts:85`
— plus the private `DAYS` (:69) and `midnight` (:71) that serve only it — has
one consumer: `entry.test.ts`. This is the deliberate bet of ADR 0006:20, that
the helper "outlives the first thing to need it", restated in the comment at
`entry.ts:76-79`. Either honour the ADR and keep it, or decide against it:
delete ~27 production lines and ~30 test lines and amend the ADR. A decision,
not a cleanup. Medium.

**`readEntries` carries a `months` parameter nothing passes.**
`src/data/store.ts:94-98`. All sixteen call sites — every module screen,
`exercises.tsx`, `report.ts`, and `store.ts` itself — pass one argument. The
archived plan flagged it (P2:285); the sync layer it anticipated shipped
without calling `readEntries` at all. Drop the parameter, the ternary at
:95-98, and the doc-comment line about it. Medium.

**Eleven exports have zero importers anywhere.** `writeText`
(`store.ts:44`), `recodeBodyPhoto` (`photos.ts:84`), `ensureFolders`
(`drive.ts:230`), the `DriveFile` type (`drive.ts:292`), `Scale`
(`food.ts:42`), `Nutrition` (`food.ts:86`), `Field` (`exercise.ts:12`),
`Mark` (`exercise.ts:28`), `Library` (`exercise.ts:30`), `Profile`
(`profile.ts:15`), `ORIGINAL` (`profile.ts:23`). No barrel re-exports exist to
hide a consumer. Remove the `export` keyword from all eleven; no call site
changes. Low.

**Seven more exports exist only as test seams.** `push` and `pull`
(`sync.ts:66,99`), `fit`, `drawAt` and `bodyPhotoPath`
(`photos.ts:25,34,100`), `localAdapter` and `readText` (`store.ts:24,40`).
Three carry comments saying so (`photos.ts:33`: jsdom has no canvas). Either
accept them as documented seams — this list is the inventory — or unexport
them and route the tests through `syncNow`, `putPhoto` and `readJson`. Low.

**Two CSS rules style markup that was deleted.** `.movement-rail-blocks`
(`src/screens/movement.css:75-81`) lost its markup in `4232b9a`;
`.nutrition-change` (`src/screens/nutrition.css:193-202`) lost its button in
`b6d1e8d`. Both grep to exactly one hit — the rule itself. Delete both blocks.
Medium.

**One parameter is dead by the compiler's own count.** `library` in
`foodItems`, `src/data/report.ts:318` — the single TS6133 that
`tsc --noUnusedLocals --noUnusedParameters` finds in the whole project. Remove

## The same code written more than once

**The module CSS skeleton is the largest duplication in the source.** The
root flex column, `-strip`, `-back`, `-split`, `-rail`, `-rail-label`,
`-rail-progress`, `-rail-page`, `-new`, `-actions`, and most of the 760px
media query are byte-identical across `workout.css`, `nutrition.css`,
`movement.css` and `dance.css` (prefix-normalized pairwise diffs share 204–244
lines), with `body.css` and `edit_entry.css` carrying subsets — and
`dance.css:1-5` admits it in as many words. This is the `OPEN.md` skeleton
item; see the stale-docs section for its count. The fix the files themselves
ask for: hoist the prefix-invariant rules into one shared stylesheet and leave
only genuinely per-module rules behind. High.

**`report.ts` re-implements sentences the screens already own.**
`src/data/report.ts:158-160` rebuilds nutrition's amount-and-unit measure
expression from `nutrition.tsx:39-41`; `report.ts:206` renders
`${span_hours} h · ${sitting_hours} sitting`, character-for-character the body
of `postureLine` at `movement.tsx:51-52`; its dance section re-derives what
`sessionLine` produces. (The report's date formatters are not duplicates —
they are deliberately offset-aware, per its own comment.) Move the payload
formatters into the data layer and have both sides call them. Medium.

**`sessionLine` and `segmentLine` are one function, twice.**
`dance.tsx:24-25` and `movement.tsx:45-46` have verbatim-identical bodies over
the same `{ duration_min, level }` shape. Merge into one shared helper — which
also removes the stray `export` on `sessionLine`, which nothing imports.
Medium.

**The config-merge defence is written four times, not three.**
`({ ...appSeed.X, ...readJson('config/app.json', appSeed).X })` appears at
`food.ts:81-84`, `movement.tsx:34-37`, `dance.tsx:35-38`, and — found by the
verifier, uncounted by the copies' own comments — `photos.ts:21`. The root
cause is the `ensureSeeded` backfill gap already tracked in `OPEN.md`; fixing
that removes the need for the defence entirely, which is the better end state
than a shared helper. Medium.

**The list-screen shell is the same block four times.** The
`open`/`past`/keyed-Builder/`onClose`-re-read state machine and the
`progress · N X, not enough to draw` paragraph repeat across
`workout.tsx:427-449`, `nutrition.tsx:362-385`, `movement.tsx:391-417` and
`dance.tsx:186-205` (movement's sentinel is `'segment' | 'posture'` rather
than `'new'`; `body.tsx:173` carries a variant of the paragraph). A shared
hook plus a progress-line helper would leave each screen supplying only its
Builder and rows. Medium.

**Two small pairs ride along.** The `today`/`isToday` two-liner is verbatim in
`workout.tsx:434-435`, `nutrition.tsx:370-371` and `movement.tsx:398-399`; the
`drop()` cursor-clamp — subtle index arithmetic that would drift silently — is
identical in `workout.tsx:209-214` and `nutrition.tsx:174-179`. Both fold
naturally into the shell consolidation above. Low.

## Stale documentation

**`DESIGN.md` still gives a walk segment a difficulty.** Lines 383–385 say a
segment records "a duration, a speed level and a difficulty". The build cut
that axis: the payload at `movement.tsx:27` is duration and level only, the
comment at `movement.tsx:360-361` says "no second axis asking how hard it
was", and `DESIGN.md:200-204`, `RULES.md:85` and `CONTEXT.md:199` all record
the cut. The archived plan flagged this exact sentence. Delete "and a
difficulty". High — it is the spec contradicting itself.

**Five of §14's eight "deferred decisions" have been decided.** Storage format
(ADR 0001, `store.ts`), plus/minus polarity (`DESIGN.md:210-212`, `parseMark`,
signed marks in the seed), seed library contents (`src/seed/*.json`), level
multipliers (`levels.json`: 0.7 / 1.0 / 1.4, matching §8.2), and host/OAuth
(`firebase.json`, ADR 0005). Only the provocation pool, sleep, and the
line-corpus language remain genuinely open — verified absent from the code.
Drop the five rows or point each at where it was decided. Medium.

**§7.3 calls storage deferred; ADR 0001 and 0002 decided it.** "Not decided
here, and may differ per module" — it is decided, built, and the opposite of
per-module: one entry shape, month files in a visible Drive folder, a
localStorage mirror. `DESIGN.md` is a maintained living spec (it took a dated
addition on 2026-08-06), so this reads as current and is not. Rewrite §7.3 to
cite the ADRs. Medium.

**§7's delete-refusal rule holds for exercises only.** The
`DeleteRefused`/`usedBy` machinery exists solely on the exercise path; foods
(`nutrition.tsx:164-170`) and segments (`movement.tsx:198-204`) delete
unconditionally, their comments citing only the "nothing in a seed list is
protected" half of §7, with read-time fallbacks (`asFood`, `asSegment`)
absorbing the orphans. Deliberate in code, unrecorded in docs. Either scope
the spec rule to exercises and state the fallback behaviour, or record the gap
as an `OPEN.md` item. Medium.

**`OPEN.md`'s skeleton count is stale: six is now eight.** `profiles.css`
(PR #11) and `exercises.css` (PR #15) both carry the 52/56px strip, the back
link and the 760px block. The entry at `OPEN.md:82-86` predates them. Update
the count and the file list. Medium.

**`OPEN.md`'s threshold-literal references drifted.** The `60_000` it cites
at `fields.tsx:68` now sits at `fields.tsx:76`, and a third `60_000` landed at
`report.ts:49` — a minutes-to-milliseconds conversion like the `entry.ts:31`
one, so the parenthetical excusing conversions should cover it. Low.

**"Creating and switching is the whole surface" predates starring.** Both
ADR 0004:62-63 and `OPEN.md:47-48` say it, but starring landed 2026-08-07
(PR #17) and the top of ADR 0004 already describes the starred default — the
ADR disagrees with its own closing line. Make it "creating, switching and
starring" in both places. The rename/delete gap they record remains true. Low.

**ADR 0006 undercounts the ADRs that mention objectives.** Its line 59 says
three earlier ADRs describe the removed module (0002, 0003, 0004), but
ADR 0001:14 also lists `config/objectives.json` in the Drive folder tree, a
file nothing creates anymore. Amend to four. Low.

## Configuration

**`launch.json` still says `"autoPort": true`.** The file predates the pin:
`vite.config.ts:34` now sets `port: 5173, strictPort: true` (commit
`0a358aa`), because only that origin is authorised for OAuth. `autoPort` is
not in the launch.json schema and describes drift the server will now refuse.
Remove the line. `dev.cmd` and `stop.cmd` are current — keep them. Medium.

**Five of the eight checked-in permission entries are spent.**
`.claude/settings.json` lines 4, 5, 8, 9 and 11 — git-tracked — allow: two
commands targeting `complex-plan-phase-8-0f5cf7`, an empty worktree husk; two
one-shot `sed -i` edits whose before-patterns still match at
`amount_stepper.tsx:57` and `food.ts:100`, so they remain loaded weapons; and
a grep of plan files that moved to the archive. Delete the five; keep the
generic `npm test *`, `npm run *`, `git checkout *`. Medium.

**Four entries in `.claude/settings.local.json` are dead or contradictory.**
Lines 4, 6, 7, 14: two greps of `daily_dc.html`, a file that does not exist
under that name; a spent `git init *`; and an allow for
`mcp__claude-in-chrome__tabs_context_mcp`, which the global instructions
forbid using at all. Gitignored, local-only. Delete the four lines. Low.

**`tsconfig.json` carries a flag another flag implies.**
`"isolatedModules": true` (line 13) is redundant under
`"verbatimModuleSyntax": true` on TypeScript 7.0.2 — verified empirically, not
just from the docs. Delete the line. Low.
